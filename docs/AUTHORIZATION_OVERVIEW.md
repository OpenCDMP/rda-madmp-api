# Authentication Overview

The **authentication and user management** in `rda-madmp-api` is handled through **Keycloak**, which serves as the external identity provider (IdP).  
The API does not directly manage authentication credentials; instead, it integrates with Keycloak to authenticate users and then stores key user and tenant-related data in PostgresSQL database for internal management.

---

## Authentication Flow

1. **User Authentication (via Keycloak)**  
   Users log in through **Keycloak**, which handles identity verification, access tokens, and session management.

2. **User Synchronization**  
   When a user authenticates successfully, their identity details are synchronized into the database.  
   The core user data is stored in the **`UserEntity`**, and Keycloak-related identifiers are stored in **`UserCredentialEntity`**.

---

## Data Model Overview

## `UserEntity`

The **`UserEntity`** represents an authenticated user within the system.  
It stores profile information and metadata after the user is authenticated through Keycloak.

| Field                | Type       | Description                                                                         |
|----------------------|------------|-------------------------------------------------------------------------------------|
| **`id`**             | `UUID`     | Unique identifier for the user. Generated by the system when the record is created. |
| **`name`**           | `String`   | Full name or display name of the user, as provided by Keycloak or manually updated. |
| **`createdAt`**      | `Instant`  | Timestamp of when the user record was created.                                      |
| **`updatedAt`**      | `Instant`  | Timestamp of the last modification of the user.                                     |
| **`isActive`**       | `IsActive` | Indicates if the user is active`.                                                   |
| **`additionalInfo`** | `String`   | Contains extra user details.                                                        |

---

## `UserCredentialEntity`

The **`UserCredentialEntity`** links a user to an external authentication provider.  
Each record represents a mapping between the internal user (`UserEntity`) and the **external identity** stored in Keycloak.

| Field            | Type      | Description                                                     |
|------------------|-----------|-----------------------------------------------------------------|
| **`id`**         | `UUID`    | Unique identifier for the credential record.                    |
| **`userId`**     | `UUID`    | Reference to the associated `UserEntity`.                       |
| **`externalId`** | `String`  | Identifier of the user in the external authentication provider. |
| **`createdAt`**  | `Instant` | Timestamp of when the user record was created.                  |
| **`updatedAt`**  | `Instant` | Timestamp of the last modification of the user.                 |

---

## `TenantEntity`

The **`TenantEntity`** represents an organization, project, or group within a multi-tenant environment.  
It defines the scope under which users, DMPs, and other resources are logically separated.

| Field           | Type       | Description                                                                                     |
|-----------------|------------|-------------------------------------------------------------------------------------------------|
| **`id`**        | `UUID`     | Unique identifier for the tenant.                                                               |
| **`code`**      | `String`   | Unique code or short name representing the tenant. Often used in configurations or API routing. |
| **`createdAt`** | `Instant`  | Timestamp of when the tenant was created.                                                       |
| **`updatedAt`** | `Instant`  | Timestamp of the last update of the tenant.                                                     |
| **`isActive`**  | `IsActive` | Indicates if the tenant is active.                                                              |

---

## `TenantUserEntity`

The **`TenantUserEntity`** defines the relationship between users and tenants.  
It determines which users belong to which tenants and supports multi-tenant memberships.

| Field           | Type       | Description                                                 |
|-----------------|------------|-------------------------------------------------------------|
| **`id`**        | `UUID`     | Unique identifier for the tenant-user association.          |
| **`userId`**    | `UUID`     | Reference to the associated user who belongs to the tenant. |
| **`createdAt`** | `Instant`  | Timestamp of when the tenant record was created.            |
| **`updatedAt`** | `Instant`  | Timestamp of the last modification of the tenant record.    |
| **`isActive`**  | `IsActive` | Indicates if the user in this tenant is currently active.   |
